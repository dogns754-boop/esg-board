GitHub 연결

토큰은 이 브라우저에만 저장되고 GitHub API(api.github.com)로만 보냅니다. GitHub → Settings → Developer settings → Fine-grained tokens에서 저장소를 하나만 고르고 Contents를 Read and write로 주어 만듭니다.
